# GitHub Project Kanban

## Crear el tablero

1. Entrar al repositorio en GitHub.
2. Abrir la pestana `Projects`.
3. Crear un nuevo proyecto tipo Board.
4. Agregar las columnas:
   - Backlog
   - To Do
   - In Progress
   - Review
   - Done
5. Vincular Issues y Pull Requests del repositorio.
